# GNSS 数据链路（LC76G）

本文记录本项目的 GNSS 数据通路、解析实现、测试方法与固件阶段待办。
依据：微雪官方示例 `09_LC76G_I2C`（`reference/ESP32-S3-Touch-AMOLED-1.75/examples/arduino/`）
与 `HARDWARE_REFERENCE_ZH.md`。

## 1. 硬件通路（-G 版本板载 LC76G）

| 项目 | 值 | 来源 |
|------|-----|------|
| 总线 | 共用 I2C：SCL=GPIO14，SDA=GPIO15 | 硬件参考文档 |
| 器件地址 | 写 `0x50` / 读 `0x54`（7-bit） | 官方示例 `DEVICE_ADDRESS(_R)` |
| 速率 | 官方示例用 100 kHz（共用总线上其他器件支持 400 kHz，需折中） | 硬件参考文档 |
| 复位 | 经 TCA9554 P7（`GPS_RST`） | 硬件参考文档 |
| UART 备选 | GPIO17/18 可能与 LC76G RX/TX 共用（-G 版需实测确认） | 硬件参考文档 |

**读取协议**（官方示例实测逻辑）：

```
1) 写 0x50: {0x08, 0x00, 0x51, 0xAA, 0x04, 0x00, 0x00, 0x00}
   读 0x54: 4 字节 → 数据长度 dataLength（小端）
2) 写 0x50: {0x00, 0x20, 0x51, 0xAA} + 上述 4 字节长度
   读 0x54: dataLength 字节 → **NMEA 文本块**（多行语句）
3) 官方示例每 500 ms 读一次并打印
```

> 因此我们拿到的是**标准 NMEA 语句流**，解析层与硬件解耦（见下）。

## 2. 解析实现（`simulator/ui/gnss_nmea.c`）

纯 C，无 LVGL / 硬件依赖 → 可在 PC 上单元测试，也可直接编进固件。

| 语句 | 提供的信息 |
|------|-----------|
| RMC | 定位有效性（A/V）、**地面速度**、航向、UTC 时间/日期 |
| GGA | 定位质量、**参与定位卫星数**、HDOP、海拔 |
| GSA | 定位维度（1 未定位 / 2 2D / 3 3D） |
| VTG | 速度与航向（无 RMC 时的补充来源） |
| GSV | 可见卫星数 |

要点：

1. **校验和**：`$` 与 `*` 之间所有字符 XOR，与 `*` 后两位十六进制比对；
   错误计入 `checksum_err` 并丢弃（避免半包/干扰数据污染显示）。
2. **不自己读时间**：由调用方 `gnss_set_time(now_ms)` 提供毫秒时基；
   模块记录最后一条被接受语句的时刻，`gnss_is_usable()` = 定位有效 **且** 未超时
   （`GNSS_STALE_MS`，默认 3 s）→ 断定位/数据过期时 UI 必须显示无效，**不得沿用旧速度**。
3. **两位年份世纪歧义**：`yy >= 80` 视为 19xx，否则 20xx（例：`191194` → 1994-11-19）。
4. **字节流组行**：`gnss_feed()` 逐字节喂入，遇 `\n` 解析；遇 `$` 丢弃残行
   （适配 I2C 分片读取、串口粘包/断包）。

## 3. 测试与回放（无硬件验证）

### 单元测试

```bash
cd tests && make run        # 或根目录 make -C simulator test
```

`tests/test_nmea.c` 覆盖：真实语句样本（校验和已外部核对）、校验和错误、逐字节分片、
残行重置、无定位降级、数据过期、空字段/垃圾数据不崩溃。
（2026-10-10：**44 项全部通过**。）

### 日志回放（模拟器）

```bash
# 合成一段 90 秒轨迹（含隧道断定位段）
python3 tools/make_nmea_track.py

# 模拟器按 10 倍速回放，直接驱动速度页 UI
cd simulator
./dashboard_sim --page 2 --variant 4 --nmea ../tests/data/drive_sample.nmea --nmea-speedup 10
NMEA_REPLAY_VERBOSE=1 ./dashboard_sim --offscreen --ms 3000 ... # 打印每组的解析值
```

**端到端验证记录（2026-10-10，10x 回放）**：

| 实时 | C 侧解析值 | 图像侧指针推算 | 结论 |
|------|-----------|--------------|------|
| 1.0 s（日志 9 s） | 30.00 km/h 有效 3D 9 星 | 29.3 km/h | ✓ |
| 3.0 s（日志 30 s） | 148.91 km/h | 148.1 km/h | ✓ |
| 6.0 s（日志 59 s，隧道） | 0.00 / **无效** / 定位无 | 0 km/h + 顶部 `NO FIX` | ✓ 降级正确 |

## 4. 固件阶段待办（板子到货后）

1. 实现 I2C 读取层（上述协议），**复用同一个 `gnss_nmea.c`**；
2. 处理共用 I2C 总线：与 CST9217/RTC/IMU 共享句柄，只初始化一次，速率取 100–400 kHz 折中；
3. 初始化顺序：TCA9554 P7 释放 LC76G 复位 → 等待首次定位（冷启动可能数十秒）；
4. 冷启动/天线未接时 `gnss_is_usable()` 为 false → UI 显示 `--`/`NO FIX`（已实现）；
5. 建议加 UART 备选通路验证（GPIO17/18），并实测确认装配；
6. 串口日志记录首次定位时间、卫星数变化、速度跟随延迟（里程碑 3 验收项）。
