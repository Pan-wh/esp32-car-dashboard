# UI 设计规范

> 状态：**已实现**（五表盘全部完成，像素级回归 33 项通过）。
> 遗留待定：状态标签与指针重叠的方案选择（见文末）。

## 核心约束

- 画布：466 × 466 圆形 AMOLED，深色背景优先。
- 视觉方向：现代原厂仪表 + 精致机械表盘语言（简洁、层次、留白、高对比），不照搬品牌标识。
- 一眼可读：车速/时间等核心数据醒目，次要数据弱化；避免小字、密集控件、花哨动画。
- 需考虑：白天可读性、夜间亮度、驾驶快速识读。

## 设计页面时必须先给出（AI_CONTEXT.md 第 8 节）

1. 页面用途与核心信息
2. 466×466 圆形布局方案
3. 主/次信息视觉层级
4. 字体大小、颜色、间距与触摸区域建议
5. 状态设计：正常 / 无定位 / 低速 / 数据无效 / 夜间
6. 动效必要性及对刷新率、功耗的影响
7. 真机验证方法

## 色彩基调（初稿，可调整）

- 背景：近黑深色 `#0B0D10`
- 主数据：高亮白/浅灰
- 次要数据：中灰
- 强调色：单一（用于速度等核心数值），夜间可降饱和
- 无效状态：灰色 + 明确图标/文案，绝不显示伪造值

## 待定稿：速度页五态状态标签与指针重叠（2026-10-12 实测）

**现象**：V5 速度页顶部的五态状态文字（BT OFF / WAIT GPS / NO FIX / STALE / LIVE）
在指针扫过时被指针压住，观感不佳（实测速度 100 km/h 时指针正好竖直穿过文字）。

**实测证据**（模拟器逐态截图 + 设备 `dump` 几何）：

| 项 | 数值 |
|----|------|
| 状态标签几何（真机 dump） | `pos(190,30) size 87x32`，居中 x=233 |
| 标签所处环带半径 | 约 171..203 px（自圆心 233,233） |
| 指针覆盖环带半径 | 168..220 px（`MARKER_INNER_R=168` 至外端约 220） |
| 圆屏半径 | 233 px（466 圆屏） |

→ 两者**共处同一环带**，故必然重叠。

**已尝试无效**：`lv_obj_move_foreground(s_status5)` 不能让标签盖住指针
（指针由 `lv_meter` 自身绘制流程输出，非同级子对象可比）。

**候选方案（需用户定稿）**：

| 方案 | 说明 | 代价 |
|------|------|------|
| A | 状态文字上移到刻度环外侧（y≈2..24），字号降到 20px 以放进窄带 | 字变小；顶部空间紧张 |
| B | 缩短指针外端半径（220→195），让出文字环带 | 指针变短，指向精度观感下降 |
| C | 仅非正常态才显示状态文字（LIVE 时隐藏） | 正常行驶时无状态提示 |
| D | 状态改为圆点/图标（如顶部一颗彩色小点）+ 图例 | 需重新定义视觉语言 |
| E | 保持现状（接受指针穿字） | 观感最差 |

> 注：本页设计由用户定稿（中央驾驶员插画、无大号数字），此处仅记录冲突与证据，
> 未擅自改动布局。
