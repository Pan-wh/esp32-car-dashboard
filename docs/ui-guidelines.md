# UI 设计规范

> 状态：**已实现**（**六**表盘全部完成，像素级回归 33 项通过）。

## 核心约束

- 画布：466 × 466 圆形 AMOLED，深色背景优先。
- 视觉方向：现代原厂仪表 + 精致机械表盘语言（简洁、层次、留白、高对比），不照搬品牌标识。
- 一眼可读：车速/时间等核心数据醒目，次要数据弱化；避免小字、密集控件、花哨动画。
- 需考虑：白天可读性、夜间亮度、驾驶快速识读。

## 设计页面时必须先给出（AI_CONTEXT.md 第 8 节）

1. 页面用途与核心信息
2. 466×466 圆形布局方案
3. 主/次信息视觉层级
4. 字体大小、颜色、间距与触摸区域建议
5. 状态设计：正常 / 无定位 / 低速 / 数据无效 / 夜间
6. 动效必要性及对刷新率、功耗的影响
7. 真机验证方法

## 色彩基调（初稿，可调整）

- 背景：近黑深色 `#0B0D10`
- 主数据：高亮白/浅灰
- 次要数据：中灰
- 强调色：单一（用于速度等核心数值），夜间可降饱和
- 无效状态：灰色 + 明确图标/文案，绝不显示伪造值

## 工具约定

- Figma 仅作布局原型，设计稿 ≠ 可运行代码。
- SquareLine Studio 使用前必须确认 LVGL 版本/API 与配套库兼容（AI_CONTEXT.md 提醒）。
- 资源文件放 `design/`，含许可说明（`design/assets/`）。

## 速度页状态区定稿（2026-10-14）

旧版顶部状态文字与指针共用同一环带，必然发生遮挡。当前方案已将数字速度、单位、
状态色点和五态文案统一放入底部白色圆形子仪表，并与表盘白底融合；顶部不再放状态信息。
视觉核心保持为中央驾驶员插画与指针，状态区只承担低权重的信息反馈。

驾驶员三态阈值最终为 **80 / 110 km/h**（平静 / 皱眉 / 咬牙），
演进过程与理由见 [`decisions.md`](decisions.md) D-013。
