# 设计稿：主时钟表盘 v1（默认页）

> 按 AI_CONTEXT.md 第 8 节交付要求编写。状态：**模拟器已实现并验证渲染**，真机未验证。

## 1. 页面用途与核心信息

驾驶时一眼读取**当前时间（HH:MM）**；日期+星期为次要信息。
此页为开机默认页；未来顶部预留 GNSS 状态图标区、底部预留速度显示区（接入数据后启用）。

## 2. 466×466 圆形布局方案

```
        ┌─────────────────────┐
        │    ╭───────────╮    │   外环 r=225（2px #3A4149）
        │   ╭───────────╮   │    内环 r=218（1px #2A3138）
        │  │             │  │
        │  │    10:58    │  │   时间 96px Montserrat SemiBold
        │  │             │  │    居中，光学中心线上移 16px
        │  │  OCT 10 · SAT│  │   日期 20px，中线下 52px
        │   ╰───────────╯   │
        │    ╰───────────╯    │
        └─────────────────────┘
     角部为物理不可见区（遮罩黑），圆缘灰描边=可视边界
```

- 时间：`LV_ALIGN_CENTER, (0, -16)`，字距 +4px
- 日期：`LV_ALIGN_CENTER, (0, +52)`，字距 +1px
- 顶部/底部留白：状态图标（上）与速度（下）接入前的留白区

## 3. 视觉层级

| 层级 | 元素 | 颜色 | 依据 |
|------|------|------|------|
| 主 | 时间 HH:MM | `#F2F4F7`（高亮白）96px | 驾驶首要读取 |
| 次 | 日期·星期 | `#8A919E`（中灰）20px | 弱化，避免与主数据竞争 |
| 装饰 | 双层表环 | `#3A4149` / `#2A3138` | 机械表圈层次，几乎不吸引注意力 |
| 底 | 背景 | `#0B0D10` | 近黑深底，夜间友好 |

## 4. 字体、颜色、间距与触摸区域

- 时间字体：Montserrat SemiBold 96px（OFL 1.1，源文件 `design/assets/fonts/`），
  4bit 抗锯齿；固件中约占用 ~40KB Flash。
- 日期字体：内置 Montserrat 20px（后续可换中文字体，需生成 CJK 字模）。
- 触摸：本页 v1 无交互；**上/下滑切换页面**留待多页设计（触摸热区 ≥ 60px 高）。

## 5. 状态设计

| 状态 | 表现 | 说明 |
|------|------|------|
| 正常 | 如上 | RTC 有效 |
| RTC 无效 | `--:--`，日期隐藏 | 数据无效即置灰占位，不伪造 |
| GNSS 未接入 | 本页不显示（顶部预留区为空） | 时钟页与定位解耦 |
| 夜间 | 深色底已天然适配；后续做亮度策略由 CO5300 命令控制 | 无独立夜间主题 |

## 6. 动效

**v1 无动效**。理由：时钟每秒仅更新一次文本，无动画需求；冒号呼吸/秒针平滑等
会提高刷新率，须在真机上以实际帧率与功耗评估后再决定，不在静态稿引入。

## 7. 真机验证方法（板子到手后）

1. `ui/` 目录代码并入 `firmware/dashboard/`，RTC 模块喂 `ui_clock_set_time()`。
2. 检查项：圆屏四缘无裁切；96px 数字在 1.75" 屏的实车观看距离（~60cm）下可读；
   白天强光下对比度足够（AMOLED 亮度策略后续调）。
3. 对照模拟器截图逐像素核对布局（预期真机一致，色彩以真机为准）。
