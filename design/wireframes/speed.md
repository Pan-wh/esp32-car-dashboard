## 1. 页面用途与核心信息

驾驶中**一眼读取当前车速（km/h）**，其次判断**定位是否可信**。
因此：速度数字必须最大、最醒目；GNSS 状态弱化但可辨；无定位时必须明确显示"无效"，
**绝不显示伪造速度**（对应 AI_CONTEXT 第 3 阶段要求）。

## 2. 四个变体的布局（均 466×466 圆屏）

| 变体 | 名称 | 布局 | 风格定位 |
|------|------|------|----------|
| **V1** | 数字 + 外环进度弧 | 大数字居中偏上，单位在下方（y=68），外圈 270° 进度弧（r=215，底部开口），状态在底部缺口（y=150） | 现代电动车仪表，**最简洁**，数字可读性最高 |
| **V2** | 指针速度表 | 0-200 刻度环（270°，135°→405°），白色圆头指针，刻度数字 0/40/…/200（r=148），底部数字读数 + 顶部状态 | 与**模拟时钟页同一设计语言**（机械感），但数值精度依赖读数 |
| **V3** | 超大数字 + 底部弧带 | 大数字居中（y=-30），单位 y=52，底部 80° 弧带（r=192）+ 两端 0/200 标注，顶部状态 | 延续 iPhone 极简风，**留白最多** |
| **V4** | 数字 + 分段进度条 | 大数字（y=-40），底部 24 段进度条（每段 12×10，间隔 5），顶部状态 | 运动/性能风格，进度**离散可见** |

## 2.5 V5 驾驶员表盘（用户方案，2026-10-10 定稿中）

按用户指定结构实现：

| 区域 | 内容 | 实现 |
|------|------|------|
| **外圈** | 速度刻度 0-200 km/h | `lv_meter` 双量表：41 小刻度（中灰 `#9A9A9E`，长 10）+ 7 大刻度（深灰 `#4A4A50`，长 18）；数字 0/40/80/120/160/200 在 r=178，深灰 `#3A3A40` |
| **指针** | 当前 GPS 速度 | 圆头指针，尖端 r=214，**内端由绘制回调外移到 r=152→168**（不遮挡中央插画）；深炭灰 `#2A2A2E`，**超速时转橙 `#FF9500`** |
| **中央** | 驾驶员插画（状态表情） | 230×230 `lv_img`，居中上移 24px；三态切换 |
| **底部** | 速度+时间 / GPS+航向 | 两行 26px 文字（`#1A1A1E` 近黑 / `#6A6A70` 中灰），落在刻度底部缺口（y=+150 / +180） |
| **底色** | **纯白 `#FFFFFF`**（2026-10-10 用户要求） | 与驾驶员素材白底无缝；V1-V4 仍为黑底以作对比 |

> ⚠️ **白底与 AMOLED**：白底在 AMOLED 上功耗明显高于纯黑（大面积发光），夜间也更刺眼。
> 已按用户要求实现；若日后需夜间模式，可加"深色主题"开关（素材已保留透明通道版的转换路径）。


### 驾驶员三态与切换阈值（2026-10-10 用户确认）

| 状态 | 触发（km/h） | 插画素材 | 附加表现 |
|------|-------------|---------|---------|
| 正常驾驶 | **0 – 90** | `driver_calm.png`（平静：半睁眼 + 平嘴） | 速度文字白色 |
| 激烈驾驶 | **90 – 120** | `driver_frown.png`（皱眉下撇） | — |
| **超速** | **> 120** | `driver_shout.png`（咬牙瞪眼 + 怒眉） | **速度文字转橙提醒** |

- 边界语义：`90` 属正常，`120` 属激烈，`120` 以上才算超速（代码 `>` 判定）。
- 映射表在 `tools/make_images.py` 的 `STATE_FILES`（改一处即可调整）；阈值在
  `simulator/ui/ui_speed.c` 的 `DRIVER_SPIRITED_V` / `DRIVER_SPEEDING_V`。
- 可用 `ui_speed_set_driver_state()` 强制覆盖（`UI_DRIVER_AUTO` 为按速度自动）。
- 无定位时：驾驶员回到"正常"态，底部显示 `-- km/h · 时间` 与 `NO FIX`。

**边界验证（像素级，2026-10-10）**：对 89/90/91/119/120/121 km/h 六档截图，
把屏上插画区域与三张素材做平均绝对差比对（差异越小即为当前显示）：

| 速度 | 显示 | 与 calm / frown / shout 的差异 |
|------|------|-------------------------------|
| 89, 90 | calm | **2.58** / 23.86 / 37.21 |
| 91, 119, 120 | frown | 23.77 / **2.41** / 30.43 |
| 121 | shout | 36.57 / 29.83 / **2.46** |

→ 六个边界点全部正确，且判别度充分（匹配项 ~2.5，非匹配项 23–37）。

### 插画素材工作流

**方式 A：用户逐张交付（当前素材走此路径）**

```bash
# 单张 PNG（可带透明通道）→ 统一尺寸 + 合成底色
python3 tools/prep_driver_png.py --size 230 --bg FFFFFF \
    normal=design/assets/images/source/driver_calm_src.png \
    spirited=design/assets/images/source/driver_frown_src.png \
    speeding=design/assets/images/source/driver_angry_src.png
```

`--keep-alpha` 可保留透明通道（改用 `CF_TRUE_COLOR_ALPHA`，体积 +50%，可叠任意底色）。

**方式 B：一张组图切多张**

```bash
python3 tools/cut_driver_sheet.py design/assets/images/source/driver_set.png --size 200
```

**最后一步（两种方式都需要）**：PNG → LVGL C 数组（`LV_IMG_CF_TRUE_COLOR`，RGB565）

```bash
python3 tools/make_images.py      # 按 STATE_FILES 映射转换三张素材
```

> 素材当前：230×230，白底合成（源图透明背景）。内容半径 ≤ 24+115 = 139 < 158，
> 不会碰到刻度数字；指针内端 r=168 也不会压到角色。
> Flash 占用：3 × 230×230×2 ≈ **310KB**。

## 6. 动效

- 数字/进度按 GNSS 更新频率（通常 1-10Hz）刷新，无需额外动画。
- V1/V3 的弧长变化、V4 的分段点亮为**数值直接映射**，不做缓动（避免读数滞后）。
- 若真机 GNSS 更新抖动导致数字跳变，可加"变化率限幅"平滑（真机阶段评估）。

## 7. 真机验证方法

1. `ui/` 并入固件，GNSS 模块解析 LC76G 的 NMEA（RMC/GGA）后调用
   `ui_speed_set_speed()` / `ui_speed_set_fix()`。
2. 检查项：1.75" 屏上 150px 数字的可读距离；蓝 `#0A84FF` 在强光下对比度；
   `--` 无效状态是否一眼可辨（避免误读为 0）。
3. 实车/户外测试：速度跟随延迟、断定位时的降级表现（AI_CONTEXT 里程碑 3）。
