# 设计稿：模拟指针时钟 v1（极简风格）

## 1. 页面用途与核心信息

以指针方式呈现当前时间：粗短的白色时针主导读数，细长分针提供精度，橙色秒针提供
「设备在运行」的活感。定位为数字时钟页之外的第二种表盘风格，二者可左右滑动切换。

## 2. 466×466 圆形布局方案

```
        ┌─────────────────────┐
        │        12           │  表盘 d=440（r=220，距屏缘 13px）
        │   11        1       │  ├ 分钟刻度 60 个（灰，长 8，2px）
        │  10          2      │  ├ 整点刻度 12 个（浅灰，长 16，3px）
        │  9    ╱╲     3     │  ├ 数字 1-12（白，34px，中心 r=176）
        │      ╱  ╲          │  ├ 时针 106 / 分针 154 / 秒针 166
        │  8  ╱     ╲  4    │  └ 中心点 白 18px + 橙 8px
        │    7   6   5       │
        └─────────────────────┘
     纯黑背景 #000000，无其他元素
```

| 元素 | 参数 |
|------|------|
| 表盘直径 | 440（r=220） |
| 分钟刻度 | 61 个刻度点 → 60 段 × 6°，宽 2，长 8，`#5A5A5F` |
| 整点刻度 | 13 个刻度点 → 12 段 × 30°，宽 3，长 16，`#C8C8CE` |
| 数字 | 34px Inter Regular（贴近 Apple SF Pro Display），白 `#F5F5F7`，圆心半径 176 |
| 时针 | 长 106（0.48R），宽 9，白，**圆头** |
| 分针 | 长 154（0.70R），宽 5，白，**圆头** |
| 秒针 | 长 166（0.75R），宽 3，橙 `#FF9500`，**圆头** |
| 中心点 | 白圆 18px + 橙圆 8px |

## 3. 视觉层级

时间读数靠**指针对比**而非字号：时针最粗（9px）> 分针（5px）> 秒针最细（3px，但用橙色
形成色彩焦点）。三针均为**圆头（round cap）**，观感柔和，不像直角矩形生硬。
数字（34px 白）与刻度（灰）退居背景层。

## 4. 字体、颜色、间距与触摸区域

- 数字字体：Inter Regular 34px（OFL），子集仅含 0-9，约 18KB C 源码。

### 关于「跟苹果字体一样」（重要）

Apple 的 **SF Pro 是专有字体**，授权仅限 Apple 平台使用，**不能嵌进 ESP32 固件**
（也不允许随固件再分发）。因此本项目采用开源界公认最接近 SF 的方案：

| 用途 | 字体 | 说明 |
|------|------|------|
| 模拟表盘数字 | **Inter Regular (wght=400, opsz=32)** | Inter 以 SF/Neue Haas 为设计参照，字形结构最接近 |
| 数字时钟大号时间 | **Inter ExtraLight (wght=200)** | 对应 iPhone 息屏时钟的极细字重 |
| 中文日期 | **Noto Sans SC Regular** | SF 无中文，Noto 是 Android/通用中文标准 |

若确需 SF 观感，可自行在 macOS 上用系统 SF 字体做**对比样张**，但那属于仅供比对、
不可入库/不可烧录。切换字重只需改 `tools/make_fonts.sh` 里的 `wght=` 数值。
- 刻度颜色明度差（`#5A5A5F` vs `#C8C8CE`）确保一眼区分整点与分钟。
- 触摸：本页无控件；**左右滑动切换页面**（手势热区为整屏）。

## 6. 动效与性能

- 秒针 **1Hz 跳动**（经典石英表观感）。
- ⚠️ 性能要点：`lv_meter` 指针变化会重绘整个表盘区域（约 440×440 的圆内部分）。
  1Hz 下占空比很低；代码已做**值未变化不重绘**的优化（时针每分钟才动）。
- 若日后要做**平滑扫秒**（10Hz），需在真机实测帧率与功耗后再定，不在本期引入。

## 7. 真机验证方法

1. `ui/` 代码并入固件，`ui_timesrc_now()` 换成 PCF85063 读取。
2. 检查项：1.75" 屏上刻度是否可辨（8px/16px 刻度在 466px 屏上约 1.7%/3.4% 直径）；
   橙色秒针在白针与黑底间是否足够跳眼；指针根部与中心点的遮挡是否正确。
3. 秒针跳动时观察有无明显整屏闪烁（重绘策略相关）。

## 实现要点（依据 LVGL 8.4 源码实测，避免后人踩坑）

1. **刻度角度公式是 `i * angle_range / (tick_cnt - 1)`**（分 `cnt-1` 段）：
   要得到 60 段 × 6° 必须传 **61** 个刻度；整点同理传 **13** 个（首尾在 12 点重叠）。
2. **不调用 `lv_meter_set_scale_major_ticks()` 就完全不会画刻度数字**
   （`tick_major_nth = 0` → major 恒为 false）。若要 1-12 数字，改用 `lv_label` 摆放
   （lv_meter 自带标签只会显示刻度**值**，无法显示 1-12 时钟数字）。
3. **指针角度 = `map(value, min, max, rotation, rotation + angle_range)`**；
   `rotation=270` → value 0 指向正上方，顺时针递增。
4. 量表量程取 **1 小时 = 3600 单位**，时/分/秒都能用整数精确映射：
   秒 `sec*60`、分 `min*60+sec`、时 `(h%12)*300 + min*5 + sec/12`。
5. 指针宽高与颜色由 indicator 自带，故可安全 `lv_obj_remove_style_all()` 去掉默认底/边框。
6. **圆头指针**：lv_meter 的线条指针对角是直角。LVGL 8.4 的 `lv_draw_line_dsc_t` 有
   `round_start` / `round_end` 圆头线帽字段，在 `LV_EVENT_DRAW_PART_BEGIN` 回调里判断
   `dsc->type == LV_METER_DRAW_PART_NEEDLE_LINE` 后置 1 即可获得柔和的圆头指针
   （见 `ui_analog.c` 的 `meter_draw_cb`）。

## LVGL Pro 草图限制

LVGL Pro 的内置 XML 控件里**没有 `lv_meter`**（LVGL 9 用 `lv_scale` 取代），
因此 `design/lvglpro/screens/clock_analog.xml` 用 `lv_scale` 画刻度环与数字、
三根指针为**静态旋转矩形**（定格 10:09:30）——只能确认布局/配色/字号，
**不能预览走时**。动态表现一律以模拟器为准。
